# drone-rectify

실측 기준선으로 드론·항공 사진의 **원근과 렌즈 왜곡을 동시에 보정**해, 축척이
일정한 2D 도면 바탕을 만드는 데스크톱 도구입니다.

드론 사진은 카메라가 완전히 수직이 아니고 렌즈에도 왜곡이 있어서, 사진 위에서
잰 길이는 **위치마다 축척이 다릅니다**. 이 프로그램은 현장에서 줄자로 잰 몇
개의 실측값을 기준으로 그 왜곡을 역산해, 사진 어디를 재도 같은 축척이 나오는
정사영상을 만듭니다.

> 검증 예시 — 지상해상도가 사진 안에서 2.2배까지 변하는 합성 사진에서,
> 20개의 실측(오차 2 cm)만으로 90 × 50 m 현장의 좌표를 **RMS 27 mm**로
> 복원했습니다. 같은 사진을 단일 축척으로 재면 상대오차가 11 %에 달합니다.

## 무엇을 하는가

```
       드론 사진                          정사보정 결과
  ┌───────────────────┐              ┌───────────────────┐
  │ 격자가 휘고        │   실측값     │ 격자가 직선·직교   │
  │ 위/아래 축척이 다름 │  ─────────▶ │ 어디서 재도 같은   │
  │ (원근 + 렌즈왜곡)  │   조정계산   │ 축척, 1 px = N mm │
  └───────────────────┘              └───────────────────┘
```

1. 사진 위에서 실제로 줄자를 댄 구간의 두 점을 클릭하고 잰 값을 입력합니다.
2. 프로그램이 **원근(호모그래피) + 렌즈 방사·접선 왜곡**을 한 번에 추정합니다.
3. 잔차·잉여도·조건수로 **얼마나 믿을 만한 결과인지** 숫자로 알려 줍니다.
4. 축척이 살아 있는 정사영상, CAD용 DXF, 성과표, 검사 리포트로 내보냅니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 실측 기반 보정 | 두 점 + 실측 거리를 관측으로 삼아 최소제곱 조정 |
| 기하 구속 | 직각 · 평행 · 등길이 · 직선상 · 사잇각 — 줄자 없이 얻는 강한 구속 |
| 렌즈 왜곡 | Brown-Conrady `k1, k2, k3, p1, p2` (관측 수에 따라 자동 선택) |
| 정확도 진단 | 단위중량 표준편차, 잉여도, Baarda 데이터 스누핑, Leave-one-out 교차검증 |
| 정밀 점 지정 | 8배 확대경, `cornerSubPix` 서브픽셀 스냅, 0.01 px 키보드 미세이동 |
| 결과 검증 | 보정 결과 위에서 직접 거리·면적 측정, 축척 막대 |
| 내보내기 | PNG/TIF + 월드파일, DXF(R12, 미터), CSV 성과표, 검사 리포트, 카메라 파라미터 JSON |

## 설치

Python 3.10 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

개발 모드로 설치하면 `dronerect` 명령이 생깁니다.

```bash
pip install -e .
```

## 실행

```bash
python -m dronerect
```

사진이나 프로젝트 파일을 인자로 주면 바로 엽니다.

```bash
python -m dronerect samples/synthetic.drproj
```

### 바로 시험해 보기

실제 드론 사진이 없어도, **정답을 아는 합성 사진**을 만들어 전 과정을 시험할
수 있습니다.

```bash
python -m dronerect.tools.make_synthetic --out samples
```

생성물:

- `synthetic.png` — 알려진 원근·왜곡을 넣어 합성한 "드론 사진"
- `synthetic_plane.png` — 참 지상 도면 (정답 정사영상)
- `synthetic_truth.json` — 참 파라미터와 마커의 참 좌표
- `synthetic.drproj` — 점과 실측값이 채워진 프로젝트 (열고 F5만 누르면 됨)

프로그램에서도 `파일 ▸ 검증용 합성 예제 만들기`로 같은 일을 할 수 있습니다.

## 사용 순서

1. **사진 열기** (`Ctrl+O`)
2. **실측 거리 추가** — 오른쪽 `관측` 탭에서 [실측 거리] → 두 점 클릭 → 값 입력.
   같은 종류로 계속 이어서 입력되고, `Esc`로 중단합니다.
3. **기하 구속 추가(권장)** — 도로 경계·건물 외곽처럼 실제로 직각·평행인 곳에
   [직각], [평행]을 걸어 둡니다.
4. **보정 실행** (`F5`)
5. **진단 확인** — `w`(표준화 잔차)가 빨간 항목은 조대오차 의심입니다.
   [조대오차 의심 관측 끄고 재계산]으로 한 번에 정리할 수 있습니다.
6. **좌표축 정렬(선택)** — 도면 원점과 X축 방향을 지정합니다.
7. **출력** — `출력` 탭에서 GSD를 정하고 정사영상을 생성한 뒤 내보냅니다.

### 정확도를 높이는 요령

- 실측 선분을 **사진 네 귀퉁이까지 고르게** 배치하세요. 한쪽에 몰리면 조건수가
  커져 반대편 정확도가 급격히 나빠집니다.
- **방향을 섞으세요.** 가로 방향만 재면 세로 축척이 제대로 결정되지 않습니다.
- **길이가 서로 많이 다른** 구간을 섞으면 축척과 왜곡이 잘 분리됩니다.
- 최소 7개 이상, 검증을 위해 3~5개 더 잡는 것을 권합니다.
- 점은 확대해서 찍으세요. 확대경과 코너 스냅이 기본으로 켜져 있습니다.

### 꼭 알아야 할 전제

이 보정은 대상이 **하나의 평면(지면)** 위에 있다고 가정합니다. 건물 벽면,
수목, 적치물 상단처럼 **높이가 있는 것은 기복변위(relief displacement)** 때문에
보정 후에도 위치가 어긋납니다.

- 실측 기준선은 반드시 **지면에서** 잡으세요.
- 지형에 큰 경사나 단차가 있으면 구역을 나눠 각각 보정하세요.
- 여러 장을 이어 붙인 정밀 지형 모델이 필요하면 SfM(구조광 복원) 도구가 맞습니다.
  이 프로그램은 **한 장의 사진을 도면 바탕으로 쓰는** 용도입니다.

## 원리

### 왜 5개 자유도인가

이미지 → 지상 평면 사상은 일반적으로 8자유도 호모그래피입니다. 그런데 관측이
"두 점 사이의 거리"뿐이라면, 지상 평면을 통째로 회전·평행이동시켜도 모든
거리가 그대로입니다. 즉 **3자유도(회전 1 + 평행이동 2)는 원리적으로 관측
불가능(gauge freedom)** 하고, 실제로 결정 가능한 것은 `8 − 3 = 5`자유도입니다.

그래서 호모그래피 9개 원소를 그대로 풀지 않고, 관측 가능한 5개만 최소
파라미터로 직접 다룹니다.

```
H = T(tx,ty) · R(θ) · A(s, a, b) · P(l1, l2)
                                   └─ 소실선 2 : 원근 제거 → 아핀 좌표
                    └─ 아핀→미터 3 : 축척 s, 종횡비 a, 전단 b
      └─ gauge 3 : 관측 불가. 계산 후 사용자 기준으로 사후 정렬
```

여기에 렌즈 왜곡 `k1, k2`가 붙어 **기본 7개 미지수**가 되고, 이는 실측 선분
7개 이상이면 풀린다는 뜻입니다. 관측 수가 적으면 `auto_free_params()`가 안전한
조합만 켜서 과적합을 막습니다.

### 사상 순서

```
픽셀 (u,v)
  → 정규화     n = (u−cx)/s0,  m = (v−cy)/s0      (s0 = 대각선의 절반)
  → 왜곡 제거  (nu, mu) = undistort(n, m)          Brown-Conrady 역함수
  → 원근 제거  w = 1 + l1·nu + l2·mu,  xa = nu/w,  ya = mu/w
  → 미터 변환  [X;Y] = R(θ) · s·[[1,b],[0,a]] · [xa;ya] + [tx;ty]
```

`w = 0`인 궤적이 **소실선**입니다. 그 근처는 배율이 발산하므로 프로그램이
화면에 붉은 파선으로 표시하고 경고합니다.

### 정확도 진단

측량의 조정계산 방식을 그대로 씁니다. 관측마다 표준편차를 주고 가중 잔차를
최소화한 뒤, 다음을 돌려줍니다.

| 지표 | 의미 |
| --- | --- |
| `σ₀` (단위중량 표준편차) | 입력한 σ가 현실적이면 1 근처. 크면 실측 오류나 평면 가정 위반 |
| 잉여도 `r_i` | 그 관측이 다른 관측으로 검증되는 정도. 0이면 **틀려도 알 수 없음** |
| `w` (Baarda 데이터 스누핑) | `|w| > 3.29`면 조대오차 의심 |
| 교차검증 RMS | Leave-one-out 예측잔차. 내부 잔차보다 정직한 정확도 추정 |
| 조건수 | 크면 실측 배치가 편중되어 해가 불안정 |

> 잔차가 작다고 정확한 것이 아니라, **잉여관측이 충분한데도** 잔차가 작아야
> 정확한 것입니다. 자유도 0이면 잔차는 항상 0이 나옵니다.

## 출력물

| 파일 | 내용 |
| --- | --- |
| `*_rectified.png` + `.pgw` | 정사영상과 월드파일. QGIS/CAD에서 축척이 유지된 채 열림 |
| `*.dxf` | 미터 단위 R12 DXF. 도면 요소·실측선·점을 레이어별로 |
| `*_measurements.csv` | 관측별 잔차·표준화잔차·잉여도 성과표 |
| `*_report.txt` | 정확도 요약, 경고, 전제 조건을 담은 검사 리포트 |
| `*_camera.json` | 추정된 왜곡계수. EXIF에 초점거리가 있으면 OpenCV 규약으로도 기록 |
| `*.drproj` | 프로젝트 파일(JSON). 사진은 경로만 저장 |

```

  core/
    distortion.py   Brown-Conrady 왜곡 모델과 반복 역함수

    constraints.py  관측 종류와 잔차 (거리/직각/평행/등길이/직선상/사잇각)
    solver.py       비선형 최소제곱 조정계산과 정확도 통계
    rectify.py      정사보정 격자 계획과 래스터 생성

  ui/
    image_view.py   확대경·서브픽셀 스냅이 있는 정밀 사진 뷰어

    panels.py       점 목록 · 관측 목록 · 보정 · 출력 패널
    dialogs.py      실측값 입력, 좌표축 정렬
    main_window.py  전체 작업 흐름
  tools/
    make_synthetic.py  정답을 아는 검증용 합성 사진 생성기
tests/
  test_core.py      합성 데이터 기반 복원 정확도 검증
```

## 테스트

```bash
pip install pytest
python -m pytest tests -q
```

합성 데이터로 다음을 확인합니다.

- 왜곡 모델 왕복 오차 `< 1e-10`
- 픽셀 ↔ 미터 역변환 왕복 오차 `< 1e-6 px`
- 참 파라미터 복원 및 **미사용 구간 거리의 상대오차 < 0.5 %**
- 실측값에 2 m 오타를 넣었을 때 데이터 스누핑이 그 관측을 지목
- 직각·평행 구속만 더해도 실측 4개로 1 % 이내 정확도 달성
- 전파된 표준불확도가 실제 오차와 같은 자릿수
- gauge 정렬이 모든 거리를 보존
